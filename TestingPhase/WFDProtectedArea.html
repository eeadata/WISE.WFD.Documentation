GWAssociatedProtectedArea#

Descriptive table reporting, for each groundwater body, the Protected Areas for which specific water objectives or additional standards have been set, and whether those objectives have been met.

Field

Data type

M

Description

euGroundwaterBodyCode

wiseIdentifier

[1]

Unique European identifier of the groundwater body to which specific objectives, related to an associated protected area, apply.

euProtectedAreaType

ProtectedAreaType

[1]

Type of protected area for which specific objectives may have been set for the groundwater body: ‘shellfishDesignatedWater’ or ‘drinkingWaterProtectionArea’. Specific objectives are only relevant, for groundwater bodies, for these two types of protected area. For Freshwater fish designated waters, the Nitrates Directive and the UWWTD, the WFD good status already integrates the corresponding objectives, so no information is requested for those types.

protectedAreaObjectivesSet

SpecialValue

[1]

Indicates whether specific water objectives or additional standards have been set for the associated protected area. Report only if specific objectives have actually been set for the protected area type reported in euProtectedAreaType. Quality control blocker: euProtectedAreaType = ‘shellfishDesignatedWater’ or ‘drinkingWaterProtectionArea’ combined with protectedAreaObjectivesSet = ‘no’. Valid values: ‘yes’.

protectedAreaObjectivesMet

SpecialValue

[1]

Indicates whether the specific water objectives or additional standards set for the protected area have been met. Quality control blocker: protectedAreaObjectivesSet = ‘yes’ combined with protectedAreaObjectivesMet = ‘inapplicable’. Valid values: ‘yes’, ‘no’, ‘unknown’.

SWAssociatedProtectedArea#

Descriptive table reporting, for each surface water body, the Protected Areas for which specific water objectives or additional standards have been set, and whether those objectives have been met.

Field

Data type

M

Description

euSurfaceWaterBodyCode

wiseIdentifier

[1]

Unique European identifier of the surface water body to which specific objectives, related to an associated protected area, apply.

euProtectedAreaType

ProtectedAreaType

[1]

Type of protected area for which specific objectives may have been set for the surface water body: ‘shellfishDesignatedWater’, ‘drinkingWaterProtectionArea’ or ‘natura2000’. Specific objectives are only relevant, for surface water bodies, for these three types of protected area. For Freshwater fish designated waters, bathing waters, the Nitrates Directive and the UWWTD, the WFD good status already integrates the corresponding objectives, so no information is requested for those types. Reporting of specific objectives for Nationally Designated Areas (NatDA, formerly CDDA) is also no longer requested.

euProtectedAreaCode

natura2000Identifier

[0..1]

Natura 2000 site code associated with the water body. Report if, and only if, euProtectedAreaType = ‘natura2000’. Quality control blockers: euProtectedAreaType = ‘natura2000’ combined with euProtectedAreaCode IS NULL; euProtectedAreaType = ‘shellfishDesignatedWater’ or ‘drinkingWaterProtectionArea’ combined with euProtectedAreaCode IS NOT NULL. The reported code must correspond to an identifier registered in the Natura2000 vocabulary.

protectedAreaObjectivesSet

SpecialValue

[1]

Indicates whether specific water objectives or additional standards have been set for the associated protected area. For shellfish designated waters and drinking water protection areas, report only if specific objectives have actually been set. For Natura 2000 sites, report if specific objectives have been set, or if the Natura 2000 site is not part of the pre-filled list of water-dependent sites. Quality control blocker: euProtectedAreaType = ‘shellfishDesignatedWater’ or ‘drinkingWaterProtectionArea’ combined with protectedAreaObjectivesSet = ‘no’. Valid values: ‘yes’, ‘no’.

protectedAreaObjectivesMet

SpecialValue

[1]

Indicates whether the specific water objectives or additional standards set for the protected area have been met. Quality control blocker: protectedAreaObjectivesSet = ‘yes’ combined with protectedAreaObjectivesMet = ‘inapplicable’. Valid values: ‘yes’, ‘no’, ‘unknown’, ‘inapplicable’.

ProtectedArea#

Spatial dataset of the Protected Areas designated under Article 6 and Annex IV of the WFD (drinking water protection areas, designated waters, bathing waters, sensitive areas, nitrate vulnerable zones and Natura 2000 sites), reported as polygon, line or point geometries.

Field

Data type

M

Description

geometry_polygon

MultiPolygon

[0..1]

The geometry representing the spatial extent of the spatial object, when the protected area is reported as a polygon. The geometry of a Management, Restriction or Regulation Zone can be reported using a polygon, a polyline or a point geometry. Only one type of geometry can be used for a given object.

geometry_line

MultiLineString

[0..1]

The geometry representing the spatial extent of the spatial object, when the protected area is reported as a polyline. Only linear geometries are allowed in the ProtectedAreaLine data set.

geometry_point

MultiPoint

[0..1]

The geometry representing the spatial extent of the spatial object, when the protected area is reported as a point.

inspireIdLocalId

string254

[1]

A local identifier, assigned by the data provider. The local identifier is unique within the namespace, that is, no other spatial object carries the same unique identifier. It is the responsibility of the data provider to guarantee uniqueness of the local identifier within the namespace. It is recommended that Data Providers reporting under WFD use a localId value identical to the thematicIdIdentifier value.

inspireIdNamespace

string254

[1]

Namespace uniquely identifying the data source of the spatial object. For Data Providers in countries not implementing the INSPIRE Directive, the country code can be used as placeholder.

inspireIdVersionId

string25

[0..1]

The identifier of the particular version of the spatial object, with a maximum length of 25 characters. The maximum length has been selected to allow for time stamps based on ISO 8601, for example, ‘2007-02-12T12:12:12+05:30’ as the version identifier.

thematicIdIdentifier

wiseIdentifier

[1]

Unique identifier used to identify the spatial object within the specified identification scheme. Must have the same value as euProtectedAreaCode, used in the River Basin Management Plans reporting. Protected Areas reported here must not share the same thematicIdIdentifier as any water body.

thematicIdIdentifierScheme

IdentifierScheme

[1]

Identifier defining the scheme used to assign the identifier. Data Providers must use the value ‘euProtectedAreaCode’.

beginLifespanVersion

date

[0..1]

Date at which this version of the spatial object was inserted or changed in the spatial data set. The beginLifespanVersion value must be provided if the endLifespanVersion value is provided.

endLifespanVersion

date

[0..1]

Date at which this version of the spatial object was superseded or retired in the spatial data set.

predecessorsIdentifier

wiseIdentifier

[0..n]

In a genealogy, the object(s) that has (have) been deactivated or replaced by the current object. Comma-separated list with the thematicIdIdentifier of the object(s) that were deactivated or replaced. Report if, and only if, the object replaces one or more objects that were previously reported.

predecessorsIdentifierScheme

IdentifierScheme

[0..1]

Identifier defining the scheme used to assign the identifier value(s) in the predecessorsIdentifier value. Mandatory if, and only if, one or more predecessors are reported. The value is identical to thematicIdIdentifierScheme.

successorsIdentifier

wiseIdentifier

[0..n]

In a genealogy, the newly active object(s) that replace(s) the current object. Comma-separated list with the thematicIdIdentifier of the object(s) that replace the current object. Report if, and only if, the reported object has been replaced and no longer exists (wiseEvolutionType = ‘deletion’).

successorsIdentifierScheme

IdentifierScheme

[0..1]

Identifier defining the scheme used to assign the identifier value(s) in the successorsIdentifier value. Mandatory if, and only if, one or more successors are reported.

wiseEvolutionType

WiseEvolutionType

[1]

Type of event that produced or modified the version of the object being reported (for example ‘creation’, ‘change’, ‘deletion’, ‘aggregation’, ‘splitting’). Determines the acceptable number of identifiers in the predecessorsIdentifier attribute.

nameTextInternational

string254

[1]

Name, in English. English exonym, or understandable English version of the name of the protected area. If an English version does not exist, report a transliteration of the national name to the ISO basic Latin alphabet.

nameText

string254

[1]

Name of the protected area, in the national language.

nameLanguage

Language

[1]

Language code of the language used in the nameText value. Use the ISO 639-2/B code of the national language.

designationPeriodBegin

date

[1]

Beginning of the time period defining when the management, restriction or regulation zone was legally designated or became effective in the real world.

designationPeriodEnd

date

[0..1]

End of the time period defining when the management, restriction or regulation zone was legally designated or became effective in the real world. Report if, and only if, the end of the validity period is known, or if the object has wiseEvolutionType = ‘deletion’. If not reported, the zone is assumed to remain in force indefinitely.

zoneType

ZoneType

[1]

High-level classification defining the type of Management, Restriction or Regulation Zone. Data Providers reporting under WFD may use ‘drinkingWaterProtectionArea’ or ‘designatedWaters’. Data Providers reporting under BWD must use ‘bathingWaters’. Data Providers reporting under UWWTD must use ‘sensitiveArea’. Data Providers reporting under the Nitrates Directive must use ‘nitrateVulnerableZone’.

specialisedZoneType

SpecialisedZoneType

[1]

Additional classification value which further specialises the type of management, regulation or restriction zone. The allowed values depend on the dataflow through which the protected area is reported (zoneType). For drinking water protection areas (reported under the recast DWD), the value must be one of ‘catchmentArea’, ‘waterBody’ or ‘waterAbstractionSafeguardZone’. For freshwater fish or shellfish designated waters (zoneType = ‘designatedWaters’), the value must be ‘freshwaterFishDesignatedWater’ or ‘shellfishDesignatedWater’. For nitrate vulnerable zones (zoneType = ‘nitrateVulnerableZone’), no specialised value applies. For UWWTD sensitive areas (zoneType = ‘sensitiveArea’), the value must be one of ‘catchmentOfSensitiveArea’, ‘lessSensitiveArea’, ‘coastalSensitiveArea’, ‘transitionalSensitiveArea’, ‘lakeSensitiveArea’ or ‘riverSensitiveArea’. For bathing waters (zoneType = ‘bathingWaters’), the value must be one of ‘transitionalBathingWater’, ‘lakeBathingWater’ or ‘riverBathingWater’.

legalBasisName

string254

[1]

Name of the legislative instrument establishing the protected area. If legalBasisLevel is ‘european’, a default value applies depending on zoneType/specialisedZoneType (for example, Directive 98/83/EC for drinking water protection areas, Directive 2006/7/EC for bathing waters, Directive 91/271/EEC for sensitive areas, Directive 91/676/EEC for nitrate vulnerable zones).

legalBasisLink

URL

[1]

Link to an online authoritative version of the document. If legalBasisLevel is ‘european’, the link corresponding to the default legalBasisName value must be used.

legalBasisLevel

LegislationLevelValue

[1]

The level at which the legislative instrument is adopted (‘european’, ‘international’, ‘national’ or ‘sub-national’).

relatedZoneIdentifier

wiseIdentifier

[1..n]

Reference(s) to the related water body/bodies (or, for drinking water protection areas, the related catchment area), via its thematic identifier(s). Mandatory. Unlike previous cycles, the association between the protected area and the related water body is now reported only once, in this spatial dataset (it is no longer requested in the WFD descriptive data reporting, except for Natura 2000 protected sites). The specific constraints depend on the dataflow (i.e. on the type of protected area).

relatedZoneIdentifierScheme

IdentifierScheme

[1]

Identifier defining the scheme used to assign the identifier value(s) in the relatedZoneIdentifier value. Mandatory. For example, if zoneType is ‘bathingWaters’, must be ‘euSurfaceWaterBodyCode’ (or ‘eionetSurfaceWaterBodyCode’ if the related zone is not a WFD water body).

confidentialityStatus

ConfidentialityStatusValue

[0..1]

Information about the sensitivity and confidentiality status of the protected area. New attribute, added to allow Data Providers to flag spatial data that will not be published — in particular for drinking water protected areas, to address concerns about publishing the location of some abstraction points/catchment areas.

link

URL

[0..1]

Hyperlink to where additional information about the object is available on the internet. Report only if a stable and resolvable URL can be provided to the specific object being reported. Do not provide generic URLs to institutional domains or webpages.
