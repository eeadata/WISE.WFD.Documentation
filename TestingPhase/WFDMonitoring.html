MonitoringSite#

Spatial dataset of the monitoring sites reported under Article 8 and Annex V of the WFD.

Field

Data type

M

Description

geometry_point

MultiPoint

[1]

The location of the site must be reported using a representative point (this also applies to trawl sampling).

inspireIdLocalId

string254

[1]

A local identifier, assigned by the data provider. The local identifier is unique within the namespace, that is, no other spatial object carries the same unique identifier. It is the responsibility of the data provider to guarantee uniqueness of the local identifier within the namespace. It is recommended that Data Providers reporting under WFD use a localId value identical to the thematicIdIdentifier value.

inspireIdNamespace

string254

[1]

Namespace uniquely identifying the data source of the spatial object. For Data Providers in countries not implementing the INSPIRE Directive, the country code can be used as placeholder.

inspireIdVersionId

string25

[0..1]

The identifier of the particular version of the spatial object, with a maximum length of 25 characters. The maximum length has been selected to allow for time stamps based on ISO 8601, for example, ‘2007-02-12T12:12:12+05:30’ as the version identifier.

thematicIdIdentifier

wiseIdentifier

[1]

Unique identifier used to identify the spatial object within the specified identification scheme. Unique European identifier of the monitoring site.

thematicIdIdentifierScheme

IdentifierScheme

[1]

Identifier defining the scheme used to assign the identifier. Data Providers reporting under WFD must use the value ‘euMonitoringSiteCode’. Other Data Providers must use the value ‘eionetMonitoringSiteCode’.

beginLifespanVersion

date

[0..1]

Date at which this version of the spatial object was inserted or changed in the spatial data set. The beginLifespanVersion value must be provided if the endLifespanVersion value is provided.

endLifespanVersion

date

[0..1]

Date at which this version of the spatial object was superseded or retired in the spatial data set. The endLifespanVersion value is only requested for objects that have been retired (without any replacement).

supersedesIdentifier

wiseIdentifier

[0..n]

In a genealogy, the object(s) replaced by the current object. . *Note*: Semantically, the supersedesIdentifier attribute is equivalent to the predecessorIdentifier attribute in the SurfaceWaterBody and GroundWaterBody data sets. The supersedesIdentifier value is a comma-separated list with the thematicIdIdentifier value of the existing object(s) that were replaced. The value must be reported if, and only if, the object replaces one or more objects that were previously reported. Data Providers should report a comma-separated list with the thematicIdIdentifier of the object(s) that have been replaced. This attribute does not apply to the case where a newer version of the same object is being reported. In other others, an object never replaces itself. The number of predecessors depends on the wiseEvolutionType value. The objects reported as predecessors must exist in the WISE register.

supersedesIdentifierScheme

IdentifierScheme

[0..1]

Identifier defining the scheme used to assign the identifier value(s) in the supersededIdentifier value. The value is mandatory if, and only if, one or more predecessors are reported. All predecessors must belong to the same identifier scheme. The value must be reported if, and only if, the supersedesIdentifier is reported. The supersedesIdentifierScheme value is identical to the thematicIdIdentifierScheme. In other words, the object being reported can only replace another object in the same identifier scheme.

supersededByIdentifier

wiseIdentifier

[0..n]

In a genealogy, the newly active object(s) that replaces (replace) the current object. . *Note*: Semantically, the supersededByIdentifierattribute is equivalent to the successorsIdentifier attribute in the SurfaceWaterBody and GroundWaterBody data sets. The supersededByIdentifier value is a comma-separated list with the thematicIdIdentifier of the object(s) that replace the current object. This attribute is **NOT** reported in the 4th cycle spatial datasets. It will be derived by the EEA and populated in the European datasets for the 1st, 2nd, and 3rd cycle of reporting of the WFD River Basin Management Plans, for the objects that have being replaced in subsequent reporting cycles.

supersededByIdentifierScheme

IdentifierScheme

[0..1]

Identifier defining the scheme used to assign the identifier value(s) in the supersedeByIdentifier attribute. The attribute is mandatory, if and only if one or more successors exist.

wiseEvolutionType

WiseEvolutionType

[1]

Type of event that produced or modified the version of the object being reported (for example ‘noChange’, ‘creation’, ‘deletion’, ‘aggregation’). . The wiseEvolutionType value determines the acceptable number of identifiers in the predecessorsIdentifier attribute.

nameTextInternational

string254

[1]

Name, in English. English exonym, or understandable English version of the name of the geographical feature or spatial object. . For this attribute, the language code is ‘eng’ (by definition) and is not reported. If an English version does not exist, then provide a transliteration of the national name to the ISO basic Latin alphabet (which uses the same 26 letters that comprise the English alphabet).

nameText

string254

[1]

Name, in the national language. National language endonym, or national language version of the name of the geographical feature or spatial object.

nameLanguage

Language

[1]

Language code of the language used in the nameText value. Use the ISO 639-2/B code of the national language used for the object’s geographical name.

operationalActivityPeriodBegin

date

[1]

Beginning of the period during which the EnvironmentalMonitoringFacility has been up and running.

operationalActivityPeriodEnd

date

[0..1]

End of the period during which the EnvironmentalMonitoringFacility has been up and running. Data Providers are requested to report this information if and only if the object has wiseEvolutionType = ‘deletion’.

featureOfInterestIdentifier

wiseIdentifier

[1]

Unique European identifier of the surface water body or groundwater body being monitored.

featureOfInterestIdentifierScheme

IdentifierScheme

[1]

Identifier defining the scheme used to assign the identifier. Data Providers reporting under WFD should use ‘euSurfaceWaterBodyCode’ or ‘euGroundWaterBodyCode’, as applicable. Other Data Providers should use ‘eionetSurfaceWaterBodyCode’ or ‘eionetGroundWaterBodyCode’, as applicable.

mediaMonitoredBiota

SpecialValue

[1]

Monitored environmental medium. Report ‘yes’ if biota is being monitored, report ‘no’ otherwise. At least one media must be monitored (biota, water or sediment). Valid values: ‘yes’ or ‘no’.

mediaMonitoredWater

SpecialValue

[1]

Monitored environmental medium. Report ‘yes’ if water is being monitored, report ‘no’ otherwise. At least one media must be monitored (biota, water or sediment). Valid values: ‘yes’ or ‘no’.

mediaMonitoredSediment

SpecialValue

[1]

Monitored environmental medium. Report ‘yes’ if sediment is being monitored, report ‘no’ otherwise. At least one media must be monitored (biota, water or sediment). Valid values: ‘yes’ or ‘no’.

purpose

WisePurposeOfCollectionValue

[0..n]

Purpose of collection. Optional. More than one purpose can be reported.

confidentialityStatus

ConfidentialityStatus

[1]

Information about the sensitivity and confidentiality status of the monitoring site location. By default, all data should be publicly available and free for publication, with confidentialityStatus = ‘F’. For safety or security reasons, Data Providers may flag that the *location* of some monitoring sites (e.g. drinking water abstractions) should not be published. If confidentialityStatus = ‘N’ (not from publication, restricted for internal use only) then the monitoring site’s location will not be published in the WISE data products. This flag applies only to the location data: the time series will still be made available. This flag does not prevent public access to data files delivered to Reportnet, if access to the deliveries is not restricted by the Data Provider.

link

URL

[0..1]

Hyperlink to where additional information about the object is available in the internet. Report only if a stable and resolvable URL can be provided to the specific object being reported, for example a public API endpoint. Do not provide generic URLs to institutional internet domains, sites or webpages.
