date

supersedesIdentifier

wiseIdentifier

[0..n]

In a genealogy, the object(s) replaced by the current object. [2]. Note: Semantically, the supersedesIdentifier attribute is equivalent to the predecessorIdentifier attribute in the SurfaceWaterBody and GroundWaterBody data sets.

WISE: The supersedesIdentifier value is a comma-separated list with the thematicIdIdentifier value of the existing object(s) that were replaced.
The value must be reported if, and only if, the object replaces one or more objects that were previously reported.
Data Providers should report a comma-separated list with the thematicIdIdentifier of the object(s) that have been replaced.
This attribute does not apply to the case where a newer version of the same object is being reported. In other others, an object never replaces itself.
The number of predecessors depends on the wiseEvolutionType value.
The objects reported as predecessors must exist in the WISE register.

IdentifierScheme

[0..1]

Identifier defining the scheme used to assign the identifier value(s) in the supersededIdentifier value.

WISE: The value is mandatory if, and only if, one or more predecessors are reported. All predecessors must belong to the same identifier scheme. The value must be reported if, and only if, the supersedesIdentifier is reported. The supersedesIdentifierScheme value is identical to the thematicIdIdentifierScheme. In other words, the object being reported can only replace another object in the same identifier scheme.

supersededByIdentifier

wiseIdentifier

[0..n]

In a genealogy, the newly active object(s) that replaces (replace) the current object. [2].

Note: Semantically, the supersededByIdentifierattribute is equivalent to the successorsIdentifier attribute in the SurfaceWaterBody and GroundWaterBody data sets.

WISE: The supersededByIdentifier value is a comma-separated list with the thematicIdIdentifier of the object(s) that replace the current object.

This attribute is NOT reported in the 4th cycle spatial datasets. It will be derived by the EEA and populated in the European datasets for the 1st, 2nd, and 3rd cycle of reporting of the WFD River Basin Management Plans, for the objects that have being replaced in subsequent reporting cycles.

[1]
