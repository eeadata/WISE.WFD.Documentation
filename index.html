WISE - Water Framework Directive#

Main sections#

The Water Framework Directive Documentation is organized in 4 main sections.

Data model review

Contains documentation about proposed changes for the 4ᵗʰ cycle of electronic reporting under the Water Framework Directive. The WISE GIS Guidance is also under review.

Testing phase

Contains information about each of the dataflows open for testing.

Getting started

Contains information about how to start using Reportnet3 for reporting, first steps, common problems and solutions.

Reporting phase

As soon as each dataflow is open for reporting, this section contain the final technical guidance.

Known issues#

Data model review - known issues

Contains a log of pending issues related to the data model review.

Testing phase - known issues

Contains a log of issues detected/reported during the testing phase.

Other resources#

Modelling conventions

Contains an overview of modelling conventions adopted during the data model review and/or applied to the UML diagrams.

Attribute types (datatypes)

Contains a glossary of the attribute types and controlled lists of values used in the WISE dataflows.

References

Contains the bibliography and links to the documents cited in text.

Dashboards (3rd cycle)

Contains the full list of dashboards with data reported in the 3rd, 2nd and 1st River Basin Management Plans.
